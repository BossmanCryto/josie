# Shizuku & Root Bridge

## Capabilities
- **`rish` Elevation**: Execute privileged Android OS commands bypassing standard Termux sandbox boundaries.
- **ADB Automation**: Manage wireless debugging pairings, input events, and system service broadcasts.
- **Hardware Touch/Key Simulation**: Send keyevents (`BACK`, `HOME`, `APP_SWITCH`) and touchscreen coordinates.
