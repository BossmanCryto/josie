# UNIFIED COMPOSITE EXECUTION MODE: SILENT HIGH-THROUGHPUT STYLE

User Directive (2026-10-11): "commands change style" & "running commands less and more execution".

1. **Composite Over Piece-Meal**:
   - Never run isolated exploratory commands (e.g. `cat`, `ls`, `grep`) across multiple turns.
   - Combine all logic, queries, and mutations into single composite Python or Shell execution payloads.

2. **Zero Command Noise**:
   - Execute quietly. Suppress intermediate progress chatter and status logs.
   - Never explain what commands are about to run — just run them and deliver the final result.

3. **High-Density Output Style**:
   - Keep final responses concise, structured, and factual.
   - Deliver clear bulleted summaries with clickable markdown links to any modified or created files.
